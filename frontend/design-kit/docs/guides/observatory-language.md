# The Observatory's visual language

The Aetherion Observatory is a realm dashboard: it is scanned and operated,
not read top to bottom. These are the rules its screens follow.

## The panel grammar

Every box is a UiPanel: hairline border, warm dark panel plate, inset top
highlight, a small-caps Cinzel cap, and an optional mono note on the same
baseline carrying the panel's headline number or freshness. Panels stack in
columns with 14px gaps; two-column grids for dense screens.

## Ledes before detail

Each screen opens with a sentence written from live numbers ("The house holds
904 listings from 109 sellers.") - a sentence states the realm's condition
better than a row of counters repeating it. Counters follow, mono and tabular.

## Color discipline

One accent: gold, spent on data marks and money. Green and red are semantic
only (funded/failed, income/spend). Character states use the fixed STATE
palette - color follows the entity, never its rank. Magnitude charts are
single-hue; a multi-hue ramp would invent categories the data lacks.

## Numbers

Every number is Cutive Mono with tabular numerals. Money is one-decimal gold
("81.6g"), sub-gold values in silver/copper ("1.0s", "80c"). Times are
relative and short ("45s", "2h"). Counts use en-GB thousands separators.

## Charts

Recessive tracks, thin marks, end-only axis labels, per-mark hover titles.
Peak values print as a mono note rather than a y-axis. Small multiples beat
stacking when series differ by orders of magnitude.

## Names are doors

Character names are clickable everywhere they appear; clicking opens the bot
detail rail. Names render brighter than surrounding text (text-hi against
body) to signal it.
